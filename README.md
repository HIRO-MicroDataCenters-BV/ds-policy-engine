# ds-policy-engine

Standalone policy-as-code microservice. Evaluates user permissions based on role and institute using [OPA (Open Policy Agent)](https://www.openpolicyagent.org/). Integrated services call `POST /api/v1/policies/evaluate` to get permissions.

The UI lives in a separate repository: **[ds-policy-engine-ui](https://github.com/HIRO-MicroDataCenters-BV/ds-policy-engine-ui)**.

## Layout

| Directory | Purpose |
|-----------|---------|
| `server/` | FastAPI application (Python 3.12, Poetry) |
| `server/charts/ds-policy-engine/` | Helm chart published to `gh-pages` |
| `server/alembic/` | SQLAlchemy database migrations |
| `server/policies/` | Seed Rego policies & rule data |
| `api/openapi.yaml` | OpenAPI spec — regenerated by pre-commit / CI |
| `client/` | Auto-generated Python SDK (published to PyPI as `ds_policy_engine`) |
| `tools/` | `version.sh`, `extract_openapi.py`, `client_generator/` |
| `.github/workflows/` | CI: test → build → GHCR → helm-gh-pages → GitHub Release |
| `docs/index.html` | Swagger UI landing page (served via `gh-pages`) |
| `docker-compose.yml` | Local dev: OPA + backend |

## Quickstart — local dev

```bash
# clone, then:
cp server/.env.template server/.env
docker compose up --build
# backend:  http://localhost:8000
# /docs:    http://localhost:8000/docs
# OPA:      http://localhost:8181
```

Run tests / lint locally (Python 3.12 + Poetry required):
```bash
cd server
poetry install --with dev,test
poetry run pytest
poetry run mypy app
poetry run isort app --check --diff
poetry run flake8 app --config .flake8 --statistics
poetry run black app --check --diff
```

For deeper layout / dev docs, see [server/README.md](server/README.md) and [CLAUDE.md](CLAUDE.md).

## Versioning & release

`VERSION` is the base semver. `tools/version.sh` derives per-build app/chart/docker versions for branches, PRs, and tags. Tag the commit `0.1.1` → clean semver release everywhere.
